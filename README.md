# Анти-грабли

Лендинг 7-недельной программы Константина Юманова.

Публичная версия: https://razilkik-ops.github.io/grabli2/

## Локальный запуск

```bash
npm install
npm run dev
```

## Сборка GitHub Pages

```bash
GITHUB_PAGES=true \
NEXT_PUBLIC_BASE_PATH=/grabli2 \
NEXT_PUBLIC_SITE_URL=https://razilkik-ops.github.io/grabli2/ \
npm run build:pages
```
